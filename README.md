# 我的 DSH 学习记录

一个用来记录学习 DSH（DeepSeek Harness）过程的轻量网页应用。

## 它能做什么

- 添加 / 修改 / 删除学习记录
- 按分类筛选（学习、踩坑、成果、想法）
- 关键词搜索，命中内容高亮
- 一键导出备份（JSON）或导出 Markdown
- 数据保存在本地 `records.json` 文件里，可以拷走、可以放网盘

## 怎么运行

需要 Python 3（本机路径 `D:\Python\python.exe`）。

```
双击 启动.bat
```

然后在浏览器打开：http://127.0.0.1:8765/

那个黑窗口不能关，关掉就等于服务器停止。

## 技术说明

- 前端：原生 HTML + CSS + JavaScript，无框架、无依赖
- 后端：Python 标准库 `http.server`，122 行
- 数据：单个 JSON 文件，原子写入（先写临时文件再替换，防写坏）

## 为什么用 `D:\my-website` 而不是中文路径

Windows 的 cmd 读取 bat 文件时按 GBK 解码，而文件若是 UTF-8 编码且含中文路径，会出现**字节错位**，导致命令名被吞掉字母（如 `title` 变成 `tle`），整个脚本失效。

所以这个项目的启动脚本放在纯英文路径下，bat 内不含任何中文。
