# 我的 DSH 学习记录

一个用来记录学习 DSH（DeepSeek Harness）过程的轻量网页应用。

## 它能做什么

- 添加 / 修改 / 删除学习记录
- 按分类筛选（学习、踩坑、成果、想法）
- 关键词搜索，命中内容高亮
- 一键导出备份（JSON）或导出 Markdown
- 数据保存在本地 `records.json` 文件里，可以拷走、可以放网盘

## 怎么运行

### 需要什么

- **Python 3.9 或更高版本**（下载：https://www.python.org/downloads/）
- 安装时记得勾选 **"Add Python to PATH"**

### 三步启动

1. 双击 `启动.bat`
2. 出现黑窗口，**不能关**，最小化可以
3. 浏览器打开 http://127.0.0.1:8765/

启动脚本会**自动查找 Python**，依次尝试：
1. 命令行里的 `python`
2. Windows 的 `py` 启动器
3. 常见安装目录（`D:\Python`、`C:\Python3xx`、`%LOCALAPPDATA%\Programs\Python\...` 等）

都找不到时会明确提示你装 Python，不会一闪就没。

## 技术说明

- **前端**：原生 HTML + CSS + JavaScript，无框架、无依赖
- **后端**：Python 标准库 `http.server`，约 130 行
- **数据**：单个 JSON 文件，原子写入（先写临时文件再 `os.replace` 替换，防止断电写坏）

### 接口

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/records` | 读取全部记录 |
| POST | `/api/records` | 整体覆盖写入 |
| GET | `/` | 返回 `index.html` |

## ⚠️ 两个已知问题

### 1. 所有文件都是 UTF-8 编码

`index.html`、`server.py`、`README.md` 都含中文且以 **UTF-8** 保存。用现代编辑器（VS Code、PyCharm、记事本 Win10+）打开都正常。

如果你用**旧版编辑器**打开看到乱码，是编辑器编码识别的问题，不是文件坏了。请手动选择 UTF-8。

### 2. 启动脚本内不能有中文路径

Windows 的 cmd 读取 `.bat` 时按 **GBK** 解码。如果 bat 文件是 UTF-8 编码且**内容含中文路径**，会出现**字节错位**——命令名被吞掉字母（`title` 变成 `tle`、`echo` 变成 `cho`），整个脚本失效。

所以本项目的 `启动.bat`：
- **内容里不含任何中文**
- 放在**纯英文路径**下运行最稳妥

如果你的项目放在中文目录（比如 `D:\我的项目\`），bat 里又是相对路径 `%~dp0`，理论上没问题；但一旦你在 bat 里硬编码了中文路径，就会坏。
