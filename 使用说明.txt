================================================
  我的 DSH 学习记录 —— 使用说明
================================================

【怎么用】

  双击「启动学习记录页.bat」

  会弹出一个黑窗口 + 自动打开浏览器。
  那个黑窗口【不能关】，最小化可以。
  关掉黑窗口 = 服务器停止，网页就读不到数据了。


【数据存在哪】

  records.json   ← 就在这个文件夹里

  这是真正的数据文件。你的所有记录都在里面。
  它长得像这样：
    {
      "_version": 1,
      "records": [
        { "title": "第 1 天…", "tag": "学习", ... }
      ]
    }


【为什么这个比以前好】

  以前（纯前端）：
    数据藏在浏览器里，换浏览器就看不到，清缓存可能丢。

  现在（有服务器）：
    数据存成 records.json 文件。
    · 可以复制走
    · 可以放进网盘同步
    · 可以用记事本打开看
    · 换电脑只要带上这个文件夹


【怎么备份】

  方法一：直接复制 records.json 到别处
  
  方法二：网页上点「导出备份（.json）」，下载一份带日期的
  
  两种都行。records.json 更简单。


【如果服务器没启动会怎样】

  直接双击 index.html 也能打开网页，
  但顶部会显示一条黄色提示：
  「没连上本地服务器（当前是纯浏览器模式）」
  
  这时数据只存在这个浏览器里，
  和以前一样。要存成文件就启动 .bat。


【文件都是什么】

  index.html              网页本体（界面 + 逻辑）
  server.py               服务器（Python，122 行）
  records.json            你的数据（自动生成）
  启动学习记录页.bat        双击这个启动
  启动学习记录页.bat        （下面有说明）

  其余 index.xxx备份.html 是历史版本，不用管。


【想改代码怎么办】

  打开 index.html 用记事本就能改。
  改坏了就换回 index.纯前端版备份.html 之类的旧版本。

  想让 AI 改：把需求说清楚，让它读 index.html 和 server.py。
